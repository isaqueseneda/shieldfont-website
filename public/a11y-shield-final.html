Notes

Why the full text is not only in the tooltip

A disclosure nobody opens is a disclosure nobody reads, and the readers who most need this sentence — screen reader, custom font, translator — are the least likely to be hovering an info icon. So the full explanation sits in the accessibility tree permanently, clipped off-screen, immediately after the short sentence in reading order. The visible tooltip is a second, redundant copy marked aria-hidden="true", which is what stops it being announced twice.

The info control is a real <button> with aria-expanded, openable by click and keyboard, closable with Escape. Hover-open is layered on top for mice only, behind @media (hover:hover), so a touch user is never left with an affordance that needs a pointer they do not have.

Both ends

The bottom strip is the same component with the same controls, not a cut-down copy — a reader who reaches the end of a long document should not have to scroll back to act. It stays a prop (position: "top" | "both") because on a short block it is pure redundancy, and the honest default is probably to switch on length rather than to pick one forever.

Emphasis has no italic to use

There is no shielded italic cut, and font-synthesis:none forbids faking the slant. So in the protected state *emphasis* steps up one real weight (500, a genuine Optik Medium cut) instead of slanting, and becomes true italic after unlock. That substitution is the classic typographic fallback, and it is visible here rather than silent. The alternative — build the italic cuts — turns out to be more possible than expected; see the summary that came back with this round.
